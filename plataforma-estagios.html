⚙️ Configuração necessária

Este arquivo ainda não está conectado a um backend. Sem essa configuração, o sistema não consegue compartilhar dados entre professores e alunos em dispositivos diferentes.

1. Crie um projeto Firebase (gratuito)

Acesse console.firebase.google.com, crie um projeto, ative:

  • Authentication → Sign-in method → ative Google, Email/senha e Microsoft (para Microsoft, veja a aba Configuração dentro do app depois de logado, ou peça as instruções ao suporte).
  • Firestore Database → criar banco (modo produção).

Depois vá em Configurações do projeto → seus apps → adicione um "App da Web" e copie o objeto firebaseConfig. Cole-o no início do <script> deste arquivo HTML, substituindo o objeto firebaseConfig de exemplo. Ajuste também a lista ADMIN_EMAILS com o(s) e-mail(s) do(s) administrador(es) iniciais.

3. Armazenamento dos documentos no Google Drive (obrigatório)

Os arquivos enviados pelos alunos (ficha, contrato, etc.) são salvos diretamente no seu Google Drive — não é usado o Firebase Storage. Acesse script.google.com, crie um projeto novo, cole o código abaixo, e implante como "Aplicativo da Web" (Implantar → Nova implantação → tipo Aplicativo da Web; Executar como: Eu; Quem pode acessar: Qualquer pessoa). Cole a URL gerada na constante DRIVE_WEBAPP_URL no topo do script deste arquivo HTML. Os arquivos vão para a raiz do "Meu Drive" dessa conta, já nomeados com turma/aluno/tipo de documento — importante: use Nova implantação, não apenas "Nova versão" de uma implantação já existente, e mantenha "Quem pode acessar" como Qualquer pessoa (não "Qualquer pessoa com Conta do Google", que quebra o envio pelo navegador).

Depois de preencher o firebaseConfig e salvar o arquivo, recarregue esta página.
